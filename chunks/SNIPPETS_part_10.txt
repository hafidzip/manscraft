**Per-seed hue is deliberately not in the atlas** — bucket 0 is baked as each band's
reference, and the mesher multiplies by `originColorMul(tag, group)` which is normalised
so bucket 0 → `[1,1,1]`. Two `jungle` planets therefore share pixels and differ in tint,
which is why 14 bands cover 2^64 seeds.

`animateConveyorTiles` is unaffected (conveyor tiles live in the base band only).

> **⚠️ Perf note.** 392 tiles × 256 px = ~100k painted pixels, once per session
> (vs. 50 tiles per planet landing today). Net win after the second planet visit.
> If first-frame cost matters, paint the base band + the current planet's band eagerly and
> fill remaining bands lazily on first `tileForOrigin` miss — the hook point is `buildAtlas`.

### `src/game/world/originStore.ts` — NEW (per-voxel tags, sparse)

Deliberately **not** a change to the `Chunk` class: it's a side table keyed exactly like
`WorldDeltaStore` (`chunkKey → localIndex`), so persistence folds in for free and memory
stays near zero (only *foreign* blocks get an entry).

```ts
// src/game/world/originStore.ts
import { NO_ORIGIN, type OriginTag } from '../core/origin';

/**
 * Sparse per-voxel origin tags. Only voxels whose origin DIFFERS from the planet's
 * native tag are stored, so freshly generated terrain costs 0 bytes.
 */
export class OriginStore {
  /** The tag every unlisted voxel implicitly has (this planet's own tag). */
  nativeTag: OriginTag = NO_ORIGIN;
  private overrides = new Map<number, Map<number, OriginTag>>();

  at(ck: number, li: number): OriginTag {
    return this.overrides.get(ck)?.get(li) ?? this.nativeTag;
  }

  set(ck: number, li: number, tag: OriginTag): void {
    if (!tag || tag === this.nativeTag) { this.overrides.get(ck)?.delete(li); return; }
    let m = this.overrides.get(ck);
    if (!m) this.overrides.set(ck, (m = new Map()));
    m.set(li, tag);
  }

  clearChunk(ck: number): void { this.overrides.delete(ck); }
  /** For worldDelta serialisation. */
  entries(ck: number): Iterable<[number, OriginTag]> { return this.overrides.get(ck) ?? []; }
  get size(): number {
    let n = 0; for (const m of this.overrides.values()) n += m.size; return n;
  }
}
```

The mesher's `MeshTheme.originAt` is then simply:

```ts
originAt: (x, y, z) => origins.at(chunkKey, localIndex(x, y, z))
```
