
/** Dev-only: proves the row path is bit-identical to the original scalar path. */
verifyRowExact(samples = 4096): void {
  for (let i = 0; i < samples; i++) {
    const px = (Math.random() * W) | 0, pz = (Math.random() * W) | 0;
    const k = this.computeColumn(px, pz);
    const ref = this.computeColumnScalarReference(px, pz);   // keep the old code here
    if (this.cache.height[k] !== ref.h || this.cache.biome[k] !== ref.biome) {
      throw new Error(`row/scalar divergence at ${px},${pz}`);
    }
  }
}
```

### Call sites & cleanup

* `world.ts` — during loading call `gen.prewarm(pcx, pcz, C.VIEW_DISTANCE + 2)` once, then `gen.drainPrewarm()` at the top of `update()` (it's a few hundred byte-stores, well under the frame budget). Without SAB, spend the loading screen in `prewarmSlice(..., 6)`.
* `generator.ts` — delete the lazy `if (!hCache)` block, the `.fill(-1)`, and the separate biome/mount allocations; move the elided height math into `heightFor(...)` unchanged; move the old body of `computeColumn` into `computeColumnScalarReference` and keep it dev-only for `verifyRowExact`.
* Anything testing `colHeight[k] === -1` → `isColumnReady(k)`.
* The worker needs the *same* seed and noise tables: `TerrainGenerator.attach(seed, buf)` must run the identical `reseedNoise`.

### Expected effect

| Path | Before | After |
|---|---|---|
| Cache hit | init branch + `Int16` load + compare | 3 int ops + `Uint8` load + compare, inlineable |
