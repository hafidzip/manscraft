## 10. Constraint compliance

| Constraint | How it's met |
|---|---|
| Don't break `App.tsx` inventory persistence | `App.tsx` untouched; `origin` is an optional field on `SlotItem` which already travels through the ref |
| Keep the two block-id systems separate | both kept; `crafting/categories.ts` is the only bridge, and it translates rather than merges |
| Keep the atlas approach (`TILE`/`TPR`/`ATLAS_*`) | extended with row-aligned variant bands; same canvas, same `tileUV`, same NEAREST material |
| Preserve save/load compat | `DELTA_VERSION 1→2` with an explicit v1 read path; `PlanetSave.v 1→2` with `migratePlanetSave`; v1 saves render identically (untagged → base band) |
| Deterministic, no `Math.random()` | `Rng(derive(seed, salt))` in theme/flora; `hash2`/`hashPlant` in generator/mesher; `mulberry32` in painters |

## 11. Known gaps / follow-ups

1. **One species per planet.** The tag's low nibble is planet type and the high nibble is
   seed hue, leaving no room for "two tree species on one world." If you want that, the
   cheapest route is a second sparse `speciesStore` for the rare multi-species case
   rather than widening the tag past a byte.
2. **`glow` is carried but not consumed.** `TreeShape.glow` / `GrassShape.glow` /
   `FlowerShape.glow` are derived and plumbed, but making neon/alien flora actually emit
   needs either `DEFS[id].light` per origin (currently a scalar on a shared def) or an
   emissive term in the cutout shader. I'd add a 5th `sway.w` channel = glow and multiply
   it into the fragment's emissive — one shader line, no new attributes.
3. **Item-entity / `ItemLedger` origin.** Factory belt items (`persist/ItemLedger`) store
   ids only; a log riding a conveyor loses its tag. Same one-byte widening as
   `worldDelta.ts` fixes it; out of scope for this pass and flagged in code.
4. **Furnace/crafting-table machine inventories** persist item ids per planet; add the tag
   byte there too if you want smelting to preserve provenance.
5. **`textures.ts` first-paint cost** — see the lazy-band note in §8 if the first landing
   frame regresses.

That's the whole loop: one byte to rule the palette, fourteen bands to paint it, and a
category tag so a jungle log still knows how to become a stick on an ice world. 🌍🪓❄️
