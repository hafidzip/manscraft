# TASK 1 — Spaceship disappears / teleports on exit

## 1.0 Diagnosis (five independent bugs, all reproducible from the excerpts)

| # | Bug | Evidence |
|---|---|---|
| B1 | **The bob is written into the authoritative transform.** `updateParked` does `pos.y = baseY + sin(...)·0.09`, then `ensureClearance` does `baseY = max(baseY, pos.y)` and `settleHere` does `baseY = pos.y`. Every board/exit cycle ratchets `baseY` up by up to **+0.09 m**. | 1e |
| B2 | **Board and park disagree on rest height.** Board → `groundY + 1.1 + 0.35 = gy+1.45`; park → `≥ gy+1.35`. Board is not idempotent w.r.t. park. | 1e |
| B3 | **`settleHere()` clamps from above.** `min(pos.y, gy+HY+1.4)` = `gy+2.55`. Exiting at 100 m altitude **teleports the ship 97 m downward in one frame** — this is the "position changed" report. | 1e |
| B4 | **`footprintGroundY()` uses `world.highestY` (column top, i.e. tree canopy) with a stride of 2**, so it both *over*-estimates (a single tree lifts the hull) and *skips* columns (a missed pillar buries the hull). Starting the reduction at `0` also means an ocean park rests at y≈1.35. | 1e |
| B5 | **No min-image handling.** `ship.pos` is never rebased against the player while the chunk group *is* re-offset (`syncChunkOffsets` / `renderOffset`). Park near the seam and `distanceTo(player.eye())` returns ~512 → `KeyE` can't board (ship looks "gone"), and `exitShip`'s side-scan runs at unwrapped coordinates. | 1c/1e |
| B6 | **No persistence.** `placeNear()` unconditionally re-parks at spawn on every planet load. | 1a |

## 1.1 Design

* `pos` becomes the **single authoritative transform**; the bob is a *render-only* offset
  applied in `sync()`/`updateParked()`. Ratcheting is structurally impossible (fixes B1).
* One constant, `HOVER_MIN`, defines the parked altitude for **both** board and park (B2).
* `settleHere()` never teleports: it computes a target and **glides** to it (`SETTLE_RATE`),
  and the engine refuses to disembark above `SHIP_MAX_EXIT_ALTITUDE` (B3).
* `groundBeneath()` scans **every** integer column of the footprint for the first *solid*
  voxel (wrapped through `world.isSolid`), so canopies and seams are handled (B4/B5).
* `rebase(refX, refZ)` keeps the ship in the player's min-image continuum every frame (B5).
* `getTransform()/setTransform()` + `planetStore` restore the parked pose (B6).

## 1.4 Replacement functions — `src/game/vehicle/spaceship.ts:~430-520`

```ts
  // ---------------------------------------------------------------------------
  // Ground sampling. Every column of the footprint, first SOLID voxel downward.
  // `world.isSolid` wraps x/z internally, so this is seam-correct by construction.
  // ---------------------------------------------------------------------------
  private groundBeneath(): number {
    const x0 = Math.floor(this.pos.x - HX);
    const x1 = Math.floor(this.pos.x + HX);
    const z0 = Math.floor(this.pos.z - HZ);
    const z1 = Math.floor(this.pos.z + HZ);
    const hullBottom = Math.min(WORLD_HEIGHT - 1, Math.floor(this.pos.y + HY));
    let gy = 0;
    for (let x = x0; x <= x1; x++) {
      for (let z = z0; z <= z1; z++) {
        // Start at the column top (cheap early-out) but never above the hull, so
        // a ship parked *inside* a canopy measures the ground, not the leaves.
        const start = Math.min(hullBottom, this.world.highestY(x, z));
        for (let y = start; y >= 0; y--) {
          if (this.world.isSolid(x, y, z)) { if (y + 1 > gy) gy = y + 1; break; }
        }
      }
    }
    return gy;
  }

  /** Public: metres between hull bottom and the ground actually under the hull. */
  altitude(): number {
    return this.pos.y - this.groundBeneath();
  }

  // ---------------------------------------------------------------------------
  // Boarding must be a NO-OP for a correctly parked ship. It only ever lifts a
  // hull that is intersecting terrain, and it never touches `baseY` upward.
  // ---------------------------------------------------------------------------
  ensureClearance(margin = 0): void {
    const safeY = this.groundBeneath() + HOVER_MIN + margin;
    if (this.pos.y < safeY) this.pos.y = safeY;
    this.baseY = this.pos.y;            // ← assignment, NOT Math.max: kills the ratchet
    this.settleT = 0;
    this.sync();
  }

  private sync(): void {
    this.group.position.set(this.pos.x, this.pos.y + this.bobY, this.pos.z);
    this.group.rotation.set(this.pitchVis, this.yaw, this.bank, 'YXZ');
    this.flame.scale.setScalar(0.6 + this.load * 2.6 + Math.sin(this.bobT * 31) * 0.12 * this.load);
  }

  // ---------------------------------------------------------------------------
  // Park in place. NEVER teleports: `snap` is only used for load/restore.
  // Idempotent — calling it twice on an unchanged world is a fixed point.
  // ---------------------------------------------------------------------------
  settleHere(snap = false): void {
    const gy = this.groundBeneath();
    const target = Math.max(gy + HOVER_MIN, Math.min(this.pos.y, gy + HOVER_MAX));
    this.vel.set(0, 0, 0);
    this.pitchVis = 0;
    this.flyPitch = 0;
    this.bank = 0;
    this.baseY = target;
    if (snap || Math.abs(target - this.pos.y) < 0.02) {
      this.pos.y = target;
      this.settleT = 0;
    } else {
      // glide; duration scales with the drop so a 20 m auto-land is not a snap
      this.settleT = Math.max(0.4, Math.abs(target - this.pos.y) / LAND_SPEED);
    }
    this.sync();
    this.group.rotation.set(0, this.yaw, 0);
  }

  updateParked(dt: number): void {
    this.bobT += dt;
    this.vel.set(0, 0, 0);

    if (this.settleT > 0) {
      this.settleT = Math.max(0, this.settleT - dt);
      this.pos.y += (this.baseY - this.pos.y) * Math.min(1, dt * SETTLE_RATE);
      if (Math.abs(this.baseY - this.pos.y) < 0.005) { this.pos.y = this.baseY; this.settleT = 0; }
    } else {
      this.pos.y = this.baseY;          // authoritative: the bob is NOT in here
    }
    this.bobY = Math.sin(this.bobT * 1.05) * BOB_AMPL;

    this.load += (0.12 - this.load) * Math.min(1, dt * 2);
    const pulse = 0.5 + 0.12 * Math.sin(this.bobT * 3);
    this.glowMat.color.setRGB(0.4 * pulse + 0.2, 0.55 * pulse + 0.2, 0.7 * pulse + 0.25);
    this.light.intensity = 1.5 + Math.sin(this.bobT * 6) * 0.4;
    this.flame.material.opacity = 0.16 + 0.06 * Math.sin(this.bobT * 9);
    this.flame.scale.setScalar(0.5 + Math.sin(this.bobT * 7) * 0.05);

    this.group.position.set(this.pos.x, this.pos.y + this.bobY, this.pos.z);
    this.group.rotation.set(0, this.yaw, 0);
  }
