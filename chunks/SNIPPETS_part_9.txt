## 3. Why grass can no longer come out blank

| Failure mode | Defence |
|---|---|
| tallgrass painter returns all-null | `guardTile` counts opaque pixels; `< 34` ⇒ `fallbackTuft()` (9 blades, 12 px base row) |
| grass top over-tinted to black | `meanLuma()` floor of 34; tile is scaled up if darker |
| grass top has alpha holes | `fillHoles(mid)` — grass_top is always 100 % opaque |
| planet-type skips grass mesh | `MUST_HAVE_GRASS` set forces `present` for terran/jungle/savanna/alien/neon/ocean/tundra |
| double-tint washout | painted tiles are never `tintTile`d; machines get 0.22 grade only |
| alphaTest 0.4 eating thin blades | blades are thickened in the lower 45 % and given a `P.sh` base row |
| stale atlas after regen | textures disposed + recreated in `init()`, `TextureSet.paint` exposes the context used |
