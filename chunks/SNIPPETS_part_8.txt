## 3.2 Patch — `src/game/engine/constants.ts`

Already carried in **4.2** and **4.4**:
`GRASS_SHADOW_RADIUS 0 → 44`, `GRASS_SHADOW_HYSTERESIS 6`, `GRASS_SHADOW_CUT [22, 28]`,
`CUTOUT_SHADOW_PUSH 0.16`.

**Why 44 for the chunk-level radius — two independent derivations that agree:**

* Near frustum: `32 + chunkHalfDiagonal(11.32) = 43.32` → no caster edge can appear
  *inside* the near frustum, which would read as a hard shadow line across the field.
* Blade dissolve: the dissolve ends at 28 m from an anchor that is at most ~3 m stale, so
  every blade that still casts is within 31 m of the camera and lives in a chunk whose
  centre is within `31 + 11.32 = 42.3` m.

`44 ≥ max(43.32, 42.3)` ✅. Hysteresis 6 keeps chunks out to 50 m, which is nearly free:
their blades are already dissolved to zero height.

## 3.3 Patch — `src/game/engine.ts:464-528` (FULL replacement of `mats.cutoutDepth`)

```ts
    mats.cutoutDepth = new THREE.MeshDepthMaterial({
      depthPacking: THREE.RGBADepthPacking,
      map: this.textures.atlas,
      alphaTest: 0.4,
      side: THREE.DoubleSide,
    });
    mats.cutoutDepth.onBeforeCompile = (shader: THREE.WebGLProgramParametersWithUniforms) => {
      // NOTE: uGrassTime / uGrassCam / uGrassYaw are GONE from this material.
      // Anything view- or time-dependent here is a shimmer generator.
      shader.uniforms.uShadowLightDir = SHADOW_LIGHT_DIR;
      shader.uniforms.uShadowPush = SHADOW_CASTER_PUSH;
      shader.uniforms.uGrassShadowAnchor = GRASS_SHADOW_ANCHOR;
      shader.uniforms.uGrassShadowCut = GRASS_SHADOW_CUT;
      shader.uniforms.uGrassShadowAng = GRASS_SHADOW_LIGHT_ANG;
      shader.vertexShader = shader.vertexShader
        .replace(
          '#include <common>',
          `#include <common>
           attribute vec4 aSway;
           uniform vec3  uShadowLightDir;      // scene -> light, unit, CONSTANT
           uniform float uShadowPush;          // metres, along -lightDir
           uniform vec3  uGrassShadowAnchor;   // frozen camera pose
           uniform vec2  uGrassShadowCut;      // caster dissolve band
           uniform float uGrassShadowAng;      // light azimuth
           varying float vNoCast;`
        )
        .replace(
          '#include <begin_vertex>',
          `#include <begin_vertex>
           float gPlant = step(0.001, aSway.y);
           float gBlade = step(10.0, normal.z);
           // aSway.y = -1 -> torch. A light source casting a black shadow is
           // always wrong; flag it and discard in the fragment stage.
           vNoCast = step(aSway.y, -0.5);

           // ---- view-INDEPENDENT billboard --------------------------------
           // Identical maths to the colour pass, with the CONSTANT light
           // azimuth substituted for the camera azimuth. One blade -> one
           // silhouette, for the whole session.
           if (gBlade > 0.5) {
             float bCx = normal.x;
             float bCz = normal.y;
             float bAng = normal.z - 100.0;
             float blendedAng = bAng + 0.6 * sin(uGrassShadowAng - bAng);
             float dAng = blendedAng - bAng;
             float cosD = cos(dAng);
             float sinD = sin(dAng);
             float offX = position.x - bCx;
             float offZ = position.z - bCz;
             transformed.x = bCx + offX * cosD - offZ * sinD;
             transformed.z = bCz + offX * sinD + offZ * cosD;
             transformed.y = position.y;
           }

           // ---- FROZEN sway ------------------------------------------------
           // sin(aSway.x) == the t = 0 sample: still per-blade random, never
           // animated. Max divergence from the visible blade is gSw * gTw
           // ~= 0.13 m at the tip, i.e. ~4 near-texels, inside the PCF kernel.
           float gTw = aSway.z;
           float gH  = aSway.w;
           vec3  gWind = vec3(cos(aSway.x * 1.7), 0.0, sin(aSway.x * 1.3));
           float gSw = sin(aSway.x) * aSway.y;
           vec3 gP = transformed + gWind * (gSw * gTw) * gPlant;

           // ---- caster dissolve around the FROZEN anchor -------------------
           // Same "sink into the ground" trick the colour pass uses for its
           // fade, so casters vanish smoothly instead of popping. Because the
           // anchor only advances on the frames we rebuild the map, this term
           // is constant for every frame that reads the map.
           vec3 wp = (modelMatrix * vec4(gP, 1.0)).xyz;
           float dA = distance(wp.xz, uGrassShadowAnchor.xz);
           float cut = 1.0 - smoothstep(uGrassShadowCut.x, uGrassShadowCut.y, dA);
           gP.y -= gTw * gH * (1.0 - cut) * gPlant;
           transformed = mix(transformed, gP, gPlant);

           // ---- acne: slide every caster DOWN its own shadow ray -----------
           // Translating a caster along the light direction moves its shadow
           // footprint by EXACTLY ZERO — it slides along the ray it already
           // owns — while increasing its recorded depth. That buys 0.16 m of
           // depth margin with no silhouette change, which is what a
           // double-sided alpha-tested quad needs: its own depth varies by up
           // to ~0.2 m across its width, more than bias + normalBias can
           // cover (a world-up normalBias is nearly perpendicular to a 12.7
           // deg sun, so it contributes only 0.12 * 0.22 = 2.6 cm of depth).
           // Cost: the shadow starts ~15 cm down-sun of the blade base.
           transformed -= uShadowLightDir * uShadowPush;`
        );
      shader.fragmentShader = shader.fragmentShader
        .replace(
          '#include <common>',
          `#include <common>
           varying float vNoCast;`
        )
        .replace(
          '#include <clipping_planes_fragment>',
          `#include <clipping_planes_fragment>
           if (vNoCast > 0.5) discard;   // torches never cast`
        );
    };

    mats.foliageDepth = new THREE.MeshDepthMaterial({
      depthPacking: THREE.RGBADepthPacking,
      map: this.textures.atlas,
      alphaTest: 0.4,
      side: THREE.DoubleSide,
    });
    // Leaves are double-sided alpha-tested quads too: same free acne fix.
    mats.foliageDepth.onBeforeCompile = (shader) => {
      shader.uniforms.uShadowLightDir = SHADOW_LIGHT_DIR;
      shader.uniforms.uShadowPush = SHADOW_CASTER_PUSH;
      shader.vertexShader = shader.vertexShader
        .replace('#include <common>', `#include <common>
           uniform vec3 uShadowLightDir;
           uniform float uShadowPush;`)
        .replace('#include <begin_vertex>', `#include <begin_vertex>
           transformed -= uShadowLightDir * uShadowPush;`);
    };
```
